# AudioLab Pro 🎚️

**Интерактивный симулятор аудиофильтров и измерительный комплекс в браузере.**  
Профессиональный инструмент для моделирования кроссоверов, анализа параметров и генерации тестовых сигналов.

## 🛠️ Функциональные модули

### 1. **🧬 Симулятор кроссовера (главный инструмент)**
*   **Типы фильтров:** Линквица-Райли (LR), Баттерворта (BW), Бесселя (Bessel)
*   **Визуализация в реальном времени:**
    *   АЧХ (амплитудно-частотная характеристика) НЧ/ВЧ секций и их суммы
    *   ФЧХ (фазо-частотная характеристика)
    *   Импеданс системы
*   **Регулируемые параметры:**
    *   Частота раздела (500-5000 Гц)
    *   Значения компонентов (L1, C1, L2, C2)
    *   Ослабление ВЧ-головки (L-Pad) с расчетом резисторов
    *   Инверсия фазы для корректного суммирования

### 2. **📡 Генератор сигналов**
*   **Генератор тонов:**
    *   Диапазон: 1 Гц – 24 кГц
    *   Тип волны: синус
    *   Плавная регулировка частоты и громкости
*   **Генератор шумов:**
    *   Белый шум (равномерный спектр)
    *   Розовый шум (-3 дБ/октава)
    *   Коричневый шум (-6 дБ/октава)

### 3. **📐 Калькулятор звукового давления (SPL)**
*   Расчет уровня звукового давления по формуле:
    *   `SPL = Чувствительность + 10×log₁₀(Мощность) - 20×log₁₀(Расстояние)`
*   Интерактивные поля ввода мощности, чувствительности и расстояния
*   Индикация полученного уровня в дБ с расшифровкой (например, "как громкий разговор")

## 🧪 Техническая реализация

| Компонент | Технология | Назначение |
|-----------|------------|------------|
| **Логика и расчеты** | Чистый JavaScript (ES6+) | Математическое моделирование цепей (комплексные числа), алгоритмы фильтров, расчет SPL |
| **Визуализация** | Chart.js v4+ | Построение точных логарифмических графиков АЧХ/ФЧХ |
| **Аудио** | Web Audio API | Генерация тонов и шумов в реальном времени |
| **Интерфейс** | CSS3 (Flexbox/Grid), CSS-переменные | Адаптивный дизайн с технологичным "тёмным режимом" |
| **Развертывание** | GitHub Pages | Статический хостинг |

## 🧩 Особенности архитектуры
*   **Монолитный дизайн:** Весь код (HTML, CSS, JavaScript) содержится в одном файле `index.html` для максимальной портабельности и простоты развертывания.
*   **"Тёмный" технологичный UI:** Цветовая схема (`#1A1D24`, `#2A2F3A`) с неоновыми акцентами (`#00F2FE`, `#EC4899`) снижает нагрузку на глаза и фокусирует внимание на данных.
*   **Активная математическая модель:** Используются операции с комплексными числами для точного расчета импеданса и АЧХ/ФЧХ RLC-цепей.

## 🔧 Для разработчиков
Проект не требует сборки. Чтобы внести изменения:
1.  Клонируйте репозиторий: `git clone https://github.com/ZingiNat/audio-lab-pro.git`
2.  Откройте `index.html` в любом редакторе кода.
3.  Для локального тестирования откройте `index.html` в браузере **через локальный сервер** (например, расширение Live Server для VS Code), так как некоторые функции Web Audio API могут не работать при открытии файла напрямую (`file://`).
