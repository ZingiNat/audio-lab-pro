## 🛠️ Функционал

1.  **📊 Симулятор кроссовера**
    *   Моделирование фильтров Линквица-Райли, Баттерворта, Бесселя
    *   Визуализация АЧХ, ФЧХ и импеданса в реальном времени
    *   Настройка компонентов (катушки, конденсаторы) и L-Pad

2.  **🎛️ Генератор частот и шумов**
    *   Генерация тонов (20 Гц – 20 кГц)
    *   Белый, розовый и коричневый шум
    *   Регулировка громкости

3.  **📐 Калькулятор звукового давления (SPL)**
    *   Расчет SPL на основе мощности, чувствительности и расстояния

## 🧩 Технологии

*   Чистый HTML5, CSS3, JavaScript (ES6+)
*   Библиотека [Chart.js](https://www.chartjs.org/) для графиков
*   Web Audio API для генерации звука
*   Хостинг: GitHub Pages
